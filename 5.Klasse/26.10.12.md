**1. Notenverwaltung**

- Mehrere Noten über ein Formular eingeben
- Noten in einem Array speichern
- Durchschnitt, beste/schlechteste Note und Anzahl der positiven Noten berechnen
- Ausgabe als HTML-Tabelle

```php
<!DOCTYPE html>
<body>
<h1>Notenverwaltung</h1>
 
<h2>Geben Sie eine Liste von Noten ein, getrennt durch Beistriche</h2>
<form method="post">
<input type="text" name="noten" placeholder="z.B. 1, 3, 2, 5">
<button type="submit">Berechnen</button>
</form>
 
<?php
 
if (isset($_POST["noten"]) && trim($_POST["noten"]) != "")
{
    $teile = explode(",", $_POST["noten"]);
    $noten = [];
    $fehler = false;
 
    foreach ($teile as $teil)
    {
        $teil = trim($teil);
        // nur ganze Zahlen von 1 bis 5 erlauben
        if (ctype_digit($teil) && $teil >= 1 && $teil <= 5)
        {
            $noten[] = (int)$teil;
        }
        else
        {
            $fehler = true;
        }
    }
 
    if ($fehler || count($noten) == 0)
    {
        echo "Bitte geben Sie nur valide Noten eine (von 1 bis 5)";
    }
    else
    {
 
        $anzahl = count($noten);
        $durchschnitt = array_sum($noten) / $anzahl;
        $beste = min($noten);           //kleinste Note
        $schlechteste = max($noten);    //größte Note
 
        $positiv = 0;
 
        foreach ($noten as $n) {
            if ($n <= 4)
            {
                $positiv++;
            }
        }
 
        // Ausgabe als Tabelle 
        echo "<h2>Auswertung</h2>";
        echo "<table>";
        echo "<tr><th>Anzahl Noten</th><td>$anzahl</td></tr>";
        echo "<tr><th>Durchschnitt</th><td>" . round($durchschnitt, 2) . "</td></tr>";
        echo "<tr><th>Beste Note</th><td>$beste</td></tr>";
        echo "<tr><th>Schlechteste Note</th><td>$schlechteste</td></tr>";
        echo "<tr><th>Positive Noten</th><td>$positiv</td></tr>";
        echo "</table>";
    }
}
?>
</body>
</html>
```

**2. Passwortgenerator**

- Lännge über ein Formular festlegen
- Zufälliges Passwort erzeugen
- Optionen: Groß-/Kleinbuchstaben, Zahlen, Sonderzeichen

```php
<!DOCTYPE html>
<body>
<h1>Passwort-Generator</h1>
<form method="post">
<b>Länge:</b>
<input type="number" name="laenge" value="12"><br>
<b>Großbuchstaben</b><input type="checkbox" name="gross" checked><br>
<b>Kleinbuchstaben</b><input type="checkbox" name="klein" checked><br>
<b>Zahlen</b><input type="checkbox" name="zahlen" checked><br>
<b>Sonderzeichen</b><input type="checkbox" name="sonder checked"><br>
<button type="submit">erzeugen</button>
</form>
 
<?php
function zufallsZeichen(string $zeichen): string {
 
    // ein zufälliges Zeichen aus dem String holen
 
    return $zeichen[random_int(0, strlen($zeichen) - 1)];
 
}
 
if ($_SERVER["REQUEST_METHOD"] == "POST") {
 
    $laenge = (int)$_POST["laenge"];
 
 
    $gruppen = [];
    if (isset($_POST["gross"]))  $gruppen[] = "ABCDEFGHIJKLMNOPQRSTUVWXYZ";
    if (isset($_POST["klein"]))  $gruppen[] = "abcdefghijklmnopqrstuvwxyz";
    if (isset($_POST["zahlen"])) $gruppen[] = "0123456789";
    if (isset($_POST["sonder"])) $gruppen[] = "!@#$%&*?-_+=";
    if (count($gruppen) == 0)
    {
        echo "Bitte mindestens eine Option auswählen!";
    }
    elseif ($laenge < count($gruppen))
    {
        echo "Das Passwort ist zu kurz für alle Optionen!";
    }
    else
    {
        $alleZeichen = implode("", $gruppen);
        $passwort = "";
 
        foreach ($gruppen as $g)
        {
            $passwort .= $g[random_int(0, strlen($g) - 1)];
        }
 
        // Rest auffüllen
 
        while (strlen($passwort) < $laenge)
        {
            $passwort .= $alleZeichen[random_int(0, strlen($alleZeichen) - 1)];
        }
 
        // durchmischen
        $array = str_split($passwort);
 
        for ($i = count($array) - 1; $i > 0; $i--)
        {
            $j = random_int(0, $i);
            $tmp = $array[$i];
            $array[$i] = $array[$j];
            $array[$j] = $tmp;
        }
 
        $passwort = implode("", $array);
 
        echo "Dein Passwort: <strong>" . htmlspecialchars($passwort) . "</strong>";
    }
 
}
 
?>
</body>
</html>
```
